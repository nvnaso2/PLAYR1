Dashboard shot-zone colors should compare each player with their own recent average for that shot type, not against shared absolute percentage thresholds. Preserve the original PLAYR1 dark maroon/red-to-orange/olive-to-green palette, and map each player's own average to a distinctly green shade, never yellow. Keep a smooth, saturated, game-like gradient rather than flat neon colors. Keep actual makes, attempts, and percentages visible, and don't add separate baseline summary cards. Color communicates personal-relative performance, not a cross-player ranking. The requested reference window is up to ten recent workouts with attempts in each shot type.

**Why:** The user rejected a prior palette where the average appeared yellow and explicitly asked to restore the original heatmap scheme with a green average. Personalized scaling still matters: a beginner's typical 20% three-point rate and an experienced player's typical 80% rate should each read as their own average.

**How to apply:** Preserve separate recent baselines for three-pointers, mid-range, free throws, and layups. Keep numerical performance factual and use the original dark palette for comparison against the player's own baseline; use green at the average, and make the existing color-coded zone breakdown collapsible rather than adding a separate shot list.
