---
name: Personalized shot heat map
description: Product intent for grading Dashboard shot zones against an individual player's recent performance
---

Dashboard shot-zone colors should compare each player with their own recent average for that shot type, not against shared absolute percentage thresholds. Use a smooth, dark jewel red-to-gold-to-lime-to-emerald gradient, with the player's average at a vivid greenish lime and percentage labels spanning 0–100%; keep strong saturation for a game-like feel without switching to a flat, neon palette. Keep actual makes, attempts, and percentages visible, and don't add separate baseline summary cards. Color communicates personal-relative performance, not a cross-player ranking. The requested reference window is up to ten recent workouts with attempts in each shot type.

**Why:** The user wants a beginner's typical 20% three-point rate and an experienced player's typical 80% rate to be treated as their respective averages rather than receiving different fixed-grade colors. They prefer a continuous gradient, yellow below average, a greenish average, and darker, saturated video-game-like shades.

**How to apply:** Preserve separate recent baselines for three-pointers, mid-range, free throws, and layups. Keep numerical performance factual and use the color scale only for comparison against the player's own baseline; interpolate dark saturated shades continuously and don't return to an orange midpoint or a ±25-point legend.
