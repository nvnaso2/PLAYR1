---
name: Personalized shot heat map
description: Product intent for grading Dashboard shot zones against an individual player's recent performance
---

Dashboard shot-zone colors should compare each player with their own recent average for that shot type, not against shared absolute percentage thresholds. Keep actual makes, attempts, and percentages visible; color communicates personal-relative performance, not a cross-player ranking. The requested reference window is up to ten recent workouts with attempts in each shot type.

**Why:** The user wants a beginner's typical 20% three-point rate and an experienced player's typical 80% rate to be treated as their respective averages rather than receiving different fixed-grade colors.

**How to apply:** Preserve separate recent baselines for three-pointers, mid-range, free throws, and layups. Keep numerical performance factual and use the color scale only for comparison against the player's own baseline.
