---
name: Dashboard audience split
description: Product direction for completion-first and shooting-analysis dashboard views.
---

Keep the Dashboard organized as two switchable views: a completion/consistency view for Quick Complete players, and a separate shooting-analysis view for players who track stats. Default to the view that matches the player's saved workout logging preference, while allowing manual switching. Keep the saved Day 1 shooting baseline visible on the completion view.

**Why:** The user wants Quick Complete players to focus on consistency measures without making shooting percentages the primary dashboard, while preserving detailed shooting analysis for stat trackers.

**How to apply:** When changing dashboard navigation or metrics, keep completion totals and the Day 1 baseline distinct from shooting charts, and use the saved logging preference only as the initial view.
