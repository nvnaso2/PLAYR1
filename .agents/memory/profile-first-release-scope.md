name: Profile first-release scope
description: Deferred Profile features and the still-open Profile/Career consolidation decision
---

For the first Profile version, hide My Season, My PLAYR1 Project, and Game Day from player-facing entry points, but preserve their pages and routes for later. Keep My Profile and My Career separate until the user decides what information should be combined.

The Profile page is the primary PLAYR1 Pro value and upgrade surface: keep its Free-vs-Pro summary, value comparison, and current-plan status inline rather than sending players to a separate marketing page. Keep the four Profile shortcuts compact and icon-led: 3 Point Challenge orange/play-inspired, Journal notebook-like and non-purple, Talk Through Your Game as an orange glowing chat icon, and Game Insights linking to the four-tool library. Game Insights should communicate understanding a player's game and giving them a practical next step; avoid "diagnostic" in its tile and library copy.

**Why:** The user wants the Profile/Career decision deferred and specified that Pro details and shortcuts should be presented directly on Profile. The user later added Game Insights to Profile and moved the four lead magnets out of the main menu.

**How to apply:** When revisiting Profile, preserve the inline upgrade surface and compact shortcut treatment. Keep the four Game Insights tools grouped in their own library. Do not merge or remove Career details based on assumptions; ask for the intended summary and preserve the current structure until then.
