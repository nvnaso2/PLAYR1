---
name: Game Insights design direction
description: The user's ongoing visual direction for the Game Insights catalog, quizzes, and result screens.
---

Keep Game Insights clean, concise, visually polished, and consistent with the rest of PLAYR1.

**Why:** the user explicitly asked for the lead magnets to match the app's overall look and feel while making the questions and results easier to use.

For the quiz catalog, use graphic quiz tiles rather than physical-book styling. Keep two black/orange tiles and two black/white tiles on a pure black page, with each quiz title as the only cover copy.

**Why:** the user rejected both generic software cards and the stronger physical-book treatment; their reference favors PLAYR1's bold condensed typography, thick basketball graphics, and high-contrast black, white, and orange.

**How to apply:** use this direction when extending the catalog, quizzes, or results; preserve diagnostic behavior and answer content, and do not add book spines, page edges, or descriptive cover copy.
