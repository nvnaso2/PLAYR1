---
name: Game Insights design direction
description: The user's ongoing visual direction for the Game Insights catalog, quizzes, and result screens.
---

Keep Game Insights clean, concise, visually polished, and consistent with the rest of PLAYR1.

**Why:** the user explicitly asked for the lead magnets to match the app's overall look and feel while making the questions and results easier to use.

Keep the Game Insights catalog to a simple title and four compact quiz blocks; remove extra hero, scouting, and footer content.

**Why:** the user wants the quiz choices to be the focus and has explicitly asked to remove everything else from this page.

Stack all four quiz blocks in one vertical column at every screen size. Match the dashboard training-summary gradient from charcoal at the top to black at the bottom, with white condensed titles and orange icon accents.

**How to apply:** preserve the four quiz topics and their existing routes; keep the page concise and avoid bringing back elaborate scouting graphics or extra copy.

Make all four quiz question and result screens feel like standalone onboarding steps on a black page, not content embedded inside one large card. Keep clear progress, simple answer rows, and the existing quiz behavior.

**Why:** the user explicitly asked the unfinished and completed quizzes to match the informational onboarding flow and apply the change consistently across all four.

**How to apply:** favor open page structure with individually styled choices; preserve question copy, scoring, branching, results, saving, and back/reset controls.
