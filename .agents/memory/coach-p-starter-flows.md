name: Coach P starter flows
description: Product requirements for Coach P's four initial coaching actions and their end-to-end behavior
---

Coach P's starter set is ordered with Build my next workout in the top-left, followed by Find my biggest opportunity, Review my last training session, and Prepare for my next game. Opportunity discovery uses the player's profile and relevant data, asks two focused play-style questions, then identifies one evidence-based priority. The normal workout builder uses its preference intake and only server-owned Drill Library items. The first-run welcome chat is separate: start with a grounded profile snapshot from setup, profile/assessment, training, and all saved lead-magnet results as self-reported context, then immediately generate a catalog-backed 30-minute solo starter workout using focus-relevant evidence. State missing-duration/setting defaults honestly, keep the preview available while chat continues, and require explicit saving before training. Session review covers the latest session or a player-requested session or timeframe. Game preparation uses available player and game context without inventing schedule details.

**Why:** The user specified the first three coaching actions, asked for Build my next workout to be the first choice, and wants the welcome experience to show that Coach P understands the player's game using all saved lead-magnet history before producing a usable first workout. Preparing for the next game was selected as the fourth because it connects training and reflection to competition.

**How to apply:** Keep the regular preference-based builder distinct from the welcome-specific snapshot-and-workout flow. Give the welcome snapshot all saved lead-magnet attempts, but limit drill choices to evidence relevant to the workout focus. Keep the workout chat open after generation and preserve catalog validation and explicit save/start behavior.
