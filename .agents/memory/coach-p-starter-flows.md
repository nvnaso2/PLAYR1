name: Coach P starter flows
description: Product requirements for Coach P's four initial coaching actions and their end-to-end behavior
---

Coach P's starter set is Find my biggest opportunity, Build my next workout, Review my last training session, and Prepare for my next game. Opportunity discovery uses the player's profile and relevant data, asks two focused play-style questions, then identifies one evidence-based priority. Workout building checks profile and training history before asking for preferences, selects only server-owned Drill Library items, and previews the workout for explicit saving. Session review covers the latest session or a player-requested session or timeframe. Game preparation uses available player and game context without inventing schedule details.

**Why:** The user specified the first three coaching actions and their intended behavior. Preparing for the next game was selected as the fourth because it connects training and reflection to competition.

**How to apply:** Keep starter labels, intent routing, context loading, follow-up behavior, and the workout preview/save path aligned when changing Coach P's first-run experience.
