name: Shared onboarding trailer card
description: Product rule for the Day 1 onboarding video metadata and profile image.
---

The welcome video is a separate onboarding step before the Day 1 Hub. Its title, description, and profile image are shared across all player accounts and edited as global admin-managed content.

**Why:** The user explicitly requested that these edits persist and appear the same across every account.

**How to apply:** Keep edits behind admin authorization, save them to shared server-side storage, and load the same values in the welcome step for every account.
