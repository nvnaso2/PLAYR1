---
name: Shared onboarding trailer card
description: Product rule for the Day 1 onboarding video metadata and profile image.
---

The Day 1 onboarding trailer card's title, description, and profile image are shared across all player accounts and edited as global admin-managed content.

**Why:** The user explicitly requested that these edits persist and appear the same across every account.

**How to apply:** Keep edits behind admin authorization, save them to shared server-side storage, and have each player's Hub read the same values.
