name: Community feed baseline
description: The current Community activity feed treatment and rolling time window.
---

The current approved baseline is a uniform multi-item activity feed: no date grouping or vertical timeline rail, consistent card height/padding/icon/avatar treatment, a restrained event-color rail, and event stats in a reserved area. It is intentionally not ranked by card size.

**Why:** The user explicitly reconfirmed the uniform list as the preferred way to browse activity after trying one-at-a-time cards.

**How to apply:** Keep this treatment as the default: newest first, no date grouping or single-card navigation, and only activity from the rolling last seven days.
