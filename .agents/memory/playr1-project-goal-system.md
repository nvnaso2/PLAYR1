---
name: PLAYR1 Project goal system
description: Product and entitlement rules for the player-owned PLAYR1 Project experience
---

The primary goal experience is a player-owned PLAYR1 Project, not a fixed workout program. A Project can represent competitive, developmental, exploratory, community, enjoyment, or creative basketball directions. Coach P should use onboarding context, ask adaptive discovery questions, support uncertainty, and let the player approve the resulting project.

**Why:** A single text goal plus a fixed eight-week training schedule could not represent the different basketball stories PLAYR1 is meant to support.

**How to apply:** Keep project identity, meaning, success definition, timeline, phases, typed milestones, and next actions separate from workouts. The full Project Builder is free and quota-exempt; Pro gates the ongoing coaching loop, milestone progression, and check-ins after the Project is built. Keep discovery in Coach P; My PLAYR1 Project is the finished-plan and progress destination.

The Builder uses a short, structured discovery sequence: Coach P proposes a direction from existing player context, offers confirmation or redirection, then collects focused answers about direction, timing, current reality, and the mix of skill, mental, competition, learning, or creative support the player wants. Each prompt stores its answer options with the clarification so the choice UI can be restored after refresh.

If all discovery answers are saved but plan generation was interrupted, reopening the Project conversation must finalize the plan before presenting the Project as ready. A ready message alone is not proof that the goal is active.

**Why:** A failed generation can leave a clarifying goal with five answers and no program; treating that state as ready creates a dead-end review button and a redirect loop.

**How to apply:** On Project resume, distinguish pending discovery, saved-but-unfinalized discovery, and an active plan. Recover the middle state through the same validated plan-generation path, then allow navigation to My PLAYR1 Project.
