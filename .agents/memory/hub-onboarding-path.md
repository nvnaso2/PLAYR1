name: Hub onboarding path
description: Production Hub states and the development-only QA controls for exercising them
---

The normal production Hub remains automatic and profile-completion-based. Onboarding contains the intro trailer, a black Complete Your Profile action area with a glowing orange Complete Profile CTA leading to Edit Profile, and the shared training-start choices. Everyday contains the training snapshot, exactly three catalog-based Custom Drills suggestions selected from profile focus, experience, and position, plus PLAYR1 Tools. Replace the Custom Workout choice with one setup-informed Coach P tile in the shared training grid in both states; match the other training buttons, stack the icon above the white Coach P title in the left column, and keep the full prompt in a composer-style field to its right. Do not move the prompt under the icon/title stack. Keep five prompts per skill and rotate deterministically by the player's local calendar day, with a separate five-prompt fallback bank when no focus is available. Do not show a standalone Coach P card. Drill suggestions are deterministic, do not call AI, and rotate by local calendar day. The welcome-workout chat may offer a temporary onboarding Hub preview; it must not change the player's saved profile or normal Hub state, and the preview needs a clear return to the normal Hub.

Development may expose only Onboarding and Everyday as QA state choices; the initial state remains profile-derived. The post-setup welcome action opens a Coach P conversation with a personalized snapshot from completed setup answers and relevant saved lead-magnet answers, followed by an immediate catalog-backed starter workout. Players can continue chatting, explicitly save and start the workout, or open the temporary onboarding Hub preview. Keep the old welcome-workout route as a redirect, not a separate recap or auto-save path.

**Why:** The user wants profile-completion-based Hub states to remain automatic, the Coach P tile to follow the same icon-over-title hierarchy as the other training buttons, and prefers the prompt pill beside the icon/title stack rather than below it. Prompt wording should vary daily so the same question is not overused. Daily drill suggestions should remain deterministic and use no AI. The welcome-workout preview must remain temporary and separate from saved profile state.

**How to apply:** Keep the default Hub profile-derived and QA controls gated to development builds with only Onboarding and Everyday choices. Keep the Coach P tile in the Custom Workout position in the shared training list, put the icon above its title, allow the full prompt to wrap inside a non-editable composer-style preview to the right, and route the whole tile to the canonical Coach P page with that prompt. Select one of five focus-specific prompts, or one of five generic prompts if the focus is missing, using the local date so the selection stays stable within a day and changes the next day. Keep exactly three available public catalog drills in the daily suggestions when the library has at least three eligible entries; rotate deterministically using profile context and local date. Allow the onboarding preview only through its explicit welcome-chat action, and keep the real profile state unchanged.
