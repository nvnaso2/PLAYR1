name: Hub onboarding path
description: Post-onboarding Hub priorities and the current Coach P entry point
---

The Hub has two automatic states with no player-facing toggle. The onboarding state contains only the intro trailer, Complete Your Profile linking to Edit Profile, and training starts. The everyday state contains a training snapshot, Custom Drills, training starts, PLAYR1 Tools, and one setup-informed Coach P prompt. Profile completion—not a legacy assessment flag—controls the state.

**Why:** The latest signup and Hub requirements replace the earlier mixed Hub with a focused first-run path and a separate everyday dashboard.

**How to apply:** Keep onboarding limited to those three content groups. Do not add community or unrelated sections to either state; keep the Coach P action specific to the player's setup.
